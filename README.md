# ⚠️ Moved — this repository is no longer maintained

**Spatial Scene Definition (SSD) / `.sscene` now lives at
[daitomanabe/spatial-scene-definition](https://github.com/daitomanabe/spatial-scene-definition).**

Everything that was published here — the format reference, the header-only
C++17 reader and the example scenes — has been migrated there and is
maintained together with the implementation profile, the room datasets, the
openFrameworks viewer and the test suite. This repository is kept only so that
existing links keep resolving. It receives no further updates; please open
issues and pull requests in the new repository.
